# Material histórico

Esta carpeta está reservada para scripts o artefactos históricos que deban conservarse como antecedente, pero que no formen parte del flujo oficial del proyecto.

## Reglas

- El material de `legacy/` no se utiliza como fuente oficial de entrenamiento, evaluación o inferencia.
- Cada archivo histórico debe indicar su propósito, tamaño de muestra y motivo de conservación.
- Los scripts solo se trasladarán aquí después de que el equipo confirme cuál es la versión oficial.

En esta reorganización no se movieron ni modificaron scripts Python.
