# Primer seguimiento de septiembre

Se preservan los scripts originales de optimización de umbral y validación temporal, junto con sus exportaciones, para mantener la historia del proyecto. Sus rutas internas corresponden a su entorno original; esta carpeta no es el procedimiento oficial de reproducción.

El seguimiento consolidado se ejecuta desde [src/evaluation/seguimiento](../../src/evaluation/seguimiento/README.md). Añade controles de etiquetas, exclusión del test S9, validación previa a la evaluación, escenarios de costo/capacidad y salidas con procedencia. Sus resultados están en [results/models/seguimiento](../../results/models/seguimiento/README.md).

Las métricas de este antecedente no se presentan como evaluación del modelo S9 ni como decisión definitiva de despliegue.
